# كات ليست محمد عادل

تطبيق أندرويد (WebView) بيشغّل CutList Optimizer v1.126 محليًا بالكامل بدون إنترنت.

## بناء الـ APK على GitHub
1. ارفع كل محتويات المجلد ده على مستودع GitHub (لازم `.github/workflows/build-apk.yml` يكون موجود في الجذر).
2. افتح تبويب **Actions** ← **Build APK** ← تأكد إنه شغال (أو اضغط **Run workflow**).
3. بعد ما يخلّص، نزّل الملف من **Artifacts** باسم `CutList-Mohamed-Adel-apk`.
4. لو عملت tag بالشكل `v1.126` هيتعمل Release فيه الـ APK تلقائي.

## تحديث الحاسبة (v4)
- حاسبة محلية جديدة (`js/native-android-bridge.js`) بتشتغل زي الموقع: بحث تدريجي عن أحسن حل، نسبة تقدم، وزر "Tap to accept" بيوقف ويقبل أحسن حل لحد اللحظة.
- بتحترم كل الأوبشنز: سُمك القص، الحد الأدنى للفضلة، المواد، اتجاه الألياف، تحزيم الحواف، "لوح واحد فقط"، أولوية التحسين (أقل هدر / أقل قصات / ألواح أصغر)، واتجاه القص المفضل.

## صورة محمد (v5)
- أيقونة التطبيق (الـ APK) بقت صورتك: `mipmap-*` (مربعة ودائرية ومتكيّفة).
- شاشة بداية بكامل الشاشة: الصورة بتقرب وتبعد وبعدين تختفي (`showPhotoSplash` في MainActivity)، ومفيش شاشة بيضا ولا دايرة على أندرويد 12+.
